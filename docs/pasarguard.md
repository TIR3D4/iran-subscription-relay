# پاسارگارد به ایران

در نصب‌کننده «فقط پاسارگارد» یا نمونه `examples/pasarguard.php` را انتخاب کنید. آدرس اصلی همراه مسیر اشتراک، مثلاً `https://pasarguard.example.com/sub`، در `panels.pasarguard` باشد.

در نسخه نصب‌شده پاسارگارد، تنظیم prefix یا آدرس عمومی اشتراک را برای مدیر/اشتراک روی `https://sub.example.com` قرار دهید و مسیر را `sub` نگه دارید. محل این تنظیم بین نسخه‌ها ممکن است تفاوت داشته باشد؛ از تنظیمات عمومی/مدیر در همان نسخه استفاده کنید و لینک نهایی ساخته‌شده برای کاربر را بررسی کنید. اگر فیلد نسخه شما URL کامل می‌خواهد، نتیجه باید فقط یک `/sub/` داشته باشد. این راهنما متغیر محیطی تأییدنشده‌ای برای prefix پیشنهاد نمی‌کند.

[نمونه محیط رسمی فعلی](https://github.com/PasarGuard/panel/blob/main/.env.example) تنظیم `SUBSCRIPTION_PATH` و سازگاری `XRAY_SUBSCRIPTION_PATH` را نشان می‌دهد؛ متغیر دومی در صورت تعیین اولویت دارد. اگر مسیر را تغییر می‌دهید، upstream باید با مسیر واقعی هماهنگ باشد؛ مسیر عمومی واسط همچنان `/sub` است.

اگر تغییر env لازم بود، سرویس را با روش نصب خود بازسازی/راه‌اندازی کنید. [تست واقعی](testing.md) شامل صفحه ساب، suffixهای فرمت و کلاینت‌هاست. قالبی که از API یا مسیر منابع خارج از `/sub` استفاده می‌کند به تنظیم جداگانه نیاز دارد.
