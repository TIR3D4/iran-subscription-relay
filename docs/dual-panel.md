# هر دو پنل روی یک دامنه

نصب‌کننده «هر دو» یا `examples/dual-panel.php` را استفاده کنید. prefix عمومی هر دو پنل `https://sub.example.com` و آدرس‌های اصلی در config جداگانه باشند.

| پاسخ مرزبان | نتیجه |
|---|---|
| 200 | همان پاسخ؛ پاسارگارد بررسی نمی‌شود |
| 404 واقعی | بررسی پاسارگارد |
| 401 / 403 / 429 | همان وضعیت؛ پاسارگارد بررسی نمی‌شود |
| 500 / 502 / 503 | همان وضعیت؛ پاسارگارد بررسی نمی‌شود |
| DNS / TLS / timeout | 502 از واسط؛ پاسارگارد بررسی نمی‌شود |
| redirect | 502؛ آدرس نهایی پنل را تنظیم کنید |

توکن‌ها باید بین پنل‌ها متفاوت باشند. اگر توکن مشترک وجود داشته باشد و مرزبان پاسخ موفق بدهد، کاربر اشتراک مرزبان را می‌گیرد. پروژه نمی‌تواند یکتایی توکن‌ها را تضمین کند. حالت مشترک HA یا failover در زمان قطعی نیست.

در `config.php` ترتیب قابل ویرایش است. اگر ترتیب را عوض کنید، قاعده 404 روی پنل اول جدید اعمال می‌شود؛ راهنمای این مخزن ترتیب پیش‌فرض مرزبان سپس پاسارگارد را توضیح می‌دهد. وجود suffix و query تغییری در این قاعده نمی‌دهد.

قبل از انتشار، ثابت کنید مرزبان برای توکن پاسارگارد واقعاً 404 می‌دهد؛ برخی قالب‌ها/پروکسی‌ها پاسخ دیگری می‌دهند و جلوی fallback را می‌گیرند. [تست‌ها](testing.md).
